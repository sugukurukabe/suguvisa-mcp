# 特定技能ビザ申請 ドメイン知識

## 対象ビザ

このプロジェクトは以下の2種類のビザのみを対象とする:
- 特定技能1号（Specified Skilled Worker (i) / Pekerja Berketerampilan Spesifik (i)）
- 特定活動（特定技能準備）（Designated Activities for SSW preparation / Kegiatan Khusus untuk persiapan SSW）

派遣に関するロジックは含めない（別サービスで提供）。

## 13申請パターン

src/data/rule-sets.json に完全定義あり。以下は要約:

### 交付（1パターン）
- GRANT_01: 海外 → 特定技能1号（在留資格認定証明書交付申請）

### 変更 → 特定活動（5パターン）
- CHANGE_TOKKATSU_A: 留学 → 特定活動
- CHANGE_TOKKATSU_B: 技能実習1号 → 特定活動 ※JFT/ASAT合格+1号満了予定が条件
- CHANGE_TOKKATSU_C: 技能実習2号 → 特定活動 ※同一分野で試験免除
- CHANGE_TOKKATSU_D: 特定技能1号 → 特定活動（転職時）
- CHANGE_TOKKATSU_E: 技能実習3号 → 特定活動 ※2号と同等扱い

### 変更 → 特定技能1号（6パターン）
- CHANGE_SSW1_A: 留学 → 特定技能1号
- CHANGE_SSW1_B: 技能実習1号 → 特定技能1号 ※JFT/ASAT合格+1号満了予定が条件
- CHANGE_SSW1_C: 技能実習2号 → 特定技能1号 ★最も一般的なパターン
- CHANGE_SSW1_D: 特定技能1号 → 特定技能1号（転職）※変更申請が必要
- CHANGE_SSW1_E: 技能実習3号 → 特定技能1号
- CHANGE_SSW1_F: 特定活動 → 特定技能1号（2段階の2段目）

### 更新（1パターン）
- RENEWAL_01: 特定技能1号 → 特定技能1号（同一雇用主）

## 試験免除ルール

| 元のビザ | 技能試験 | 日本語試験 |
|---------|---------|-----------|
| 技能実習1号 | 免除なし | 免除なし |
| 技能実習2号（同一分野） | 免除 | 免除 |
| 技能実習3号（同一分野） | 免除 | 免除 |
| 特定技能1号（同一分野） | 免除 | 免除 |
| 留学 | 免除なし | 免除なし |
| 特定活動 | 元のビザによる | 元のビザによる |

技能実習1号からの申請はJFT-Basic（日本語基礎テスト）またはASAT（農業技能評価試験等）の合格が必要。

## 申請中の就労ルール

- 新しい雇用主のもとでは就労不可
- 前の雇用主のもとでは在留期限まで就労可能
- 在留期限を過ぎた特例期間中は就労不可（在留のみ認められる）

## 重要な期限

- 随時届出: 事由発生から14日以内（厳守）
- 定期届出: 毎年4月1日〜5月31日
- 更新申請: 在留期限の3ヶ月前から可能
- 特定技能1号通算: 上限5年
- 認定証明書: 交付から3ヶ月以内に査証申請
- 特定活動: 最長4ヶ月

## 入管様式のルール

- 申請書（別記第○号）: 入管の参考様式PDFをそのまま使う。値のみを提供
- CSVオンライン申請: 2026年1月16日更新版のフォーマットに準拠
- 契約書等の自由書類: 法定記載事項が含まれていれば様式は自由
- ふりがなは必ずひらがな（カタカナは不受理）
- 法人番号は13桁（国税庁の法人番号公表サイトで検証可能）

## 出力の2つの方式

1. オンライン申請CSV（generate_online_csv）: 入管オンラインシステムにアップロード
2. 紙申請PDFフォーム（generate_paper_form）: 入管様式PDFに値を入力して印刷

## 16分野

農業, 漁業, 飲食料品製造業, 外食業, 介護, ビルクリーニング,
素形材・産業機械・電気電子情報関連製造業, 建設, 造船・舶用工業,
自動車整備, 航空, 宿泊, 自動車運送業, 鉄道, 林業, 木材産業

## 母国語併記

Phase 1はインドネシア語（Bahasa Indonesia）のみ対応。
併記が必要な書類: 雇用契約書, 雇用条件書, 支援計画書, 事前ガイダンス説明資料
