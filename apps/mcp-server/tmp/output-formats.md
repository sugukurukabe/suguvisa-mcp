# 出力フォーマット スキル

## 2つの出力方式

SuguVisa MCPは書類の出力を2つの方式で提供する。
入管の様式は絶対に壊さない。

## 方式1: オンライン申請CSV（generate_online_csv）

入管オンライン申請システム（https://www.ras-immi.moj.go.jp/）に
アップロードするCSVファイルを生成する。

### CSV仕様

- フォーマット: 2026年1月16日更新版に準拠
- エンコーディング: UTF-8（BOM付き）
- 改行: CRLF
- 区切り: カンマ
- 値のクォート: ダブルクォート（値内のダブルクォートは""でエスケープ）

### バリデーション必須項目

- ふりがな: ひらがなのみ（カタカナNG）
- 法人番号: 13桁の数字
- 在留カード番号: 英字2文字+数字8桁+英数字2文字（例: AB12345678CD）
- 日付形式: YYYY-MM-DD
- 性別コード: 1=男, 2=女
- 申請種別コード: 1=認定, 2=変更, 3=更新

### 出力時のルール

- CSVの列順・列名は入管の公式仕様に厳密に従う
- 未入力のフィールドは空文字（NULLではない）
- 金額は半角数字のみ（カンマや円マークは含めない）
- 電話番号はハイフン付き（例: 099-123-4567）

## 方式2: 紙申請PDFフォーム（generate_paper_form）

入管の参考様式PDFのフォームフィールドに入力すべき値と
フィールド名のマッピングを返す。

### 対象PDF

- 在留資格認定証明書交付申請書（別記第6号の5）
- 在留資格変更許可申請書（別記第30号の5）
- 在留期間更新許可申請書（別記第30号）

### フィールドマッピングの構造

```json
{
  "page": 1,
  "field_name": "nationality",
  "label": "国籍・地域",
  "value": "インドネシア",
  "status": "filled"
}
```

status:
- "filled": 値が入力されている
- "empty": 値が未入力（ユーザーに入力を求める）
- "needs_review": 値はあるが確認が必要

### 様式保護のルール

- PDFの様式自体を改変・再生成しない
- 入管サイトからダウンロードしたオリジナルPDFを使う
- SuguVisaが提供するのは「どのフィールドに何の値を入れるか」の情報のみ
- 将来的にpdf-libでフォーム自動入力を実装する場合も、PDF構造は変更しない

## 入力シート（generate_intake_sheet）

行政書士がクライアントに渡す「記入用シート」を生成する。
これは入管の様式ではなくSuguVisa独自のフォーマット。

### 構造

```json
{
  "sections": [
    {
      "section": "申請人情報 / Applicant Info / Informasi Pemohon",
      "fields": [
        {
          "label": "氏名（ローマ字）/ Name (Romaji) / Nama (Romaji)",
          "required": true,
          "note": "パスポート表記 / As shown on passport / Sesuai paspor"
        }
      ]
    }
  ]
}
```

入力シートの項目名とnoteも3言語で記述する。
