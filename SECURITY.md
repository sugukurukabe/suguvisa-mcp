# セキュリティポリシー / Security Policy / Kebijakan Keamanan

## 脆弱性の報告 / Reporting Vulnerabilities / Melaporkan Kerentanan

セキュリティ上の脆弱性を発見された場合は、以下までご連絡ください。

If you discover a security vulnerability, please report it to:

Jika Anda menemukan kerentanan keamanan, silakan laporkan ke:

**Email**: security@suguvisa.jp

48時間以内に確認の返信をいたします。

We will respond with confirmation within 48 hours.

Kami akan merespons dengan konfirmasi dalam 48 jam.

## 対応範囲 / Scope / Cakupan

- SuguVisa MCP サーバー（このリポジトリ）
- SuguVisa Cloud Run サービス
- 関連する OAuth / 認証フロー

## 責任ある開示 / Responsible Disclosure / Pengungkapan Bertanggung Jawab

修正パッチの公開前に脆弱性の詳細を公開しないでください。

Please do not publicly disclose vulnerability details before a fix is released.

Harap jangan mengungkapkan detail kerentanan secara publik sebelum perbaikan dirilis.
